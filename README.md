# Flashless

League of Legends companion app that tracks enemy summoner spell cooldowns. A small overlay shows each
enemy's spells with a cooldown sweep, reads "used Flash" lines from the in-game chat, and builds a
one-line message for team chat (`Mid 1554f | Sup 1657f`). Written in Rust, single exe, no runtime needed.

## Features

- Enemy roster, levels, items and spells from League's Live Client API, rows in lane order (Top, Jg, Mid, ADC, Sup).
- Cooldowns with summoner spell haste: Ionian Boots, Crimson Lucidity, Cosmic Insight (manual toggle),
  ARAM, and Unleashed Teleport scaling.
- Chat reading: picks up "Enemy used Flash" lines with Windows OCR and starts the timer. Garbled
  timestamps are tolerated, and lines whose time can't be read are timed from when they appeared.
- A tracked spell starts a few seconds into its cooldown (default 7 s) for the time it takes to see and call it.
- One-line chat message, Flash first. Copy it, auto-copy on every change, or type it into chat without sending.
- Flash-back alert: the tile pulses when an enemy's Flash is up again (optional sound).
- Full and compact views, light and dark themes, Flash left / right / game order.
- Clicks pass through the overlay while League is in front (optional), hide outside games (optional).
- Keyboard and mouse (Mouse 3/4/5) hotkeys, tray icon, per-user installer and updater.

## Why Rust

Flashless started as a C# prototype. The Rust rewrite is smaller and lighter while you play:

| | Flashless (Rust) | C# prototype (small exe) | C# prototype (standalone) |
|---|---|---|---|
| File size | 7.1 MB | 25.9 MB | 65.1 MB |
| Working set (demo, idle) | ~100 MB | ~196 MB | ~324 MB |
| Threads | 18 | 32 | 31 |
| Idle CPU over 20 s | ~0 ms (redraws once a second) | 31 ms | 344 ms |
| Needs .NET | no | yes | no |

OCR time is the same in both (they call the OCR engine built into Windows). On top of that, the Rust
version crops the chat area on the GPU, only runs OCR when the chat text changes, asks Windows for at
most one captured frame a second, and polls the Live Client API every 5 s.

## Install

Download `Flashless-Setup.exe` from [Releases](../../releases). Version history: [CHANGELOG.md](CHANGELOG.md).

- `Flashless-Setup.exe`: run it, click Install. Per-user, no admin. Installs to
  `%LOCALAPPDATA%\Programs\Flashless` with Start menu and desktop shortcuts and an Installed apps entry.
  Running a newer setup or `Flashless-Update-x.y.z.exe` updates in place and keeps settings.
- Windows search finds "Flashless"; Win+R `flashless` also works.
- Uninstall: Settings > Apps > Installed apps > Flashless, or `Flashless.exe --uninstall`.
- Silent: `Flashless-Setup.exe --silent [--no-desktop] [--no-start-menu]`, `Flashless.exe --uninstall --silent`.

Settings, `chat.log` (last three games) and `error.log` live in `%LOCALAPPDATA%\Flashless`.

## Use

Click a spell tile when an enemy uses it (right click clears, wheel ±5 s), or use the hotkeys:
`Ctrl+Alt+1..5` enemy Flash, `Ctrl+Alt+C` copy the message, `Ctrl+Alt+V` type it into chat without
sending, `Ctrl+Alt+Z` undo, `Ctrl+Alt+O` hide/show. Click a champion name to set level and Cosmic Insight.
Settings (gear icon) has the roster, message options, chat area (draw / auto-detect), appearance and hotkeys.

## Build

```
cargo test
cargo build --release
```

Diagnostics:

```
Flashless.exe --ocr-test <screenshot.png> [left top width height] [champions...]
Flashless.exe --capture-test "<window title>"
```

Releasing: bump the version in `Cargo.toml` and `assets/app.rc`, add its section to `CHANGELOG.md`,
commit and push, then `scripts\release.ps1` (tags `vX.Y.Z` and publishes the installer and updater).

Signing: `scripts\sign.ps1 -DryRun` lists what would be signed; see the top of the script for the
certificate or Azure Trusted Signing setup (read from environment variables, nothing stored in the repo).

## How it is built

- UI: egui/eframe 0.29 (OpenGL), Segoe UI and Segoe icon fonts loaded from Windows.
- Windows APIs via the `windows` crate 0.58: Live Client API over loopback HTTPS (ureq + native-tls),
  Windows.Graphics.Capture with a D3D11 crop, Windows.Media.Ocr, low-level keyboard and mouse hooks,
  SendInput for Type In Chat, Win32 clipboard, tray icon, IShellLink + registry for the installer.
- Art: the Flash spell icon (`assets/flash_source.png`) with a cooldown pie and gold rim, generated by
  `assets/make_icon.py`; spell icons from Data Dragon in `assets/spells/*.rgba` (`assets/fetch_spell_icons.py`).
- `src/`: `data` (Data Dragon), `cooldown`, `tracker`, `message`, `live`, `chat` (OCR line parser),
  `settings`, `update`, `win/*` (Windows integration), `ui/*` (overlay, Settings, installer, theme, icons).
