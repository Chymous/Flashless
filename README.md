# Flashless

League of Legends companion app that tracks enemy summoner spell cooldowns, written in Rust: chat reading,
one-line cooldown message, themes, Settings, and a built-in installer. Successor of the C# SpellCall
prototype, archived in `../Archive/SpellCall-CSharp`.

| | Flashless (Rust) | C# small exe | C# standalone |
|---|---|---|---|
| File size | 6.6 MB | 25.9 MB | 65.1 MB |
| Working set (demo, idle) | ~102 MB | ~196 MB | ~324 MB |
| Threads | 18 | 32 | 31 |
| Idle CPU over 20 s | ~0 ms (redraws once a second) | 31 ms | 344 ms |
| Needs .NET | no | yes | no |

OCR time is the same in both (~35-50 ms per scan): both call the OCR engine built into Windows.

## Install / share

- `dist/Flashless-Setup.exe` (or `Flashless-Setup.zip`): run it, click Install. Per-user, no admin.
  Installs to `%LOCALAPPDATA%\Programs\Flashless`, adds "Flashless" Start menu and desktop
  shortcuts and an Installed apps entry. Running a newer setup updates in place.
- `dist/Flashless.exe`: run directly without installing.
- Windows search: the Start menu shortcut (on by default in the installer) makes "Flashless" searchable;
  Win+R `flashless` also works.
- Uninstall: Settings > Apps > Installed apps > Flashless, or `Flashless.exe --uninstall`.
- Silent: `Flashless-Setup.exe --silent [--no-desktop] [--no-start-menu]`, `Flashless.exe --uninstall --silent`.

Settings, chat.log and error.log live in `%LOCALAPPDATA%\Flashless` (moved there automatically from the old
`SpellCall-rs` folder). Do not run Flashless and the C# SpellCall at once: both react to the same hotkeys.

## Use

Same as the C# version: click a spell tile when an enemy uses it (right click clears, wheel ±5 s),
`Ctrl+Alt+1..5` for enemy Flash, `Ctrl+Alt+C` copies the message, `Ctrl+Alt+V` types it into chat
without sending, `Ctrl+Alt+Z` undo, `Ctrl+Alt+O` hide/show. Click a champion name to set level, extra
ability haste and Cosmic Insight. Rows are in lane order: Top, Jg, Mid, ADC, Sup. Settings (gear icon) has the roster, message options, chat area
(draw / auto-detect / reset), theme and hotkeys.

## How it is built

- UI: egui/eframe 0.29 (OpenGL), Segoe UI and Segoe icon fonts loaded from Windows.
- Windows APIs: the `windows` crate 0.58. Live Client API over loopback HTTPS (ureq + native-tls),
  Windows.Graphics.Capture for the game window, Windows.Media.Ocr, low-level keyboard hook,
  SendInput for Type In Chat, Win32 clipboard, IShellLink + registry for the installer.
- Icon: the Flash spell art (`assets/flash_source.png`, Riot Games) with a cooldown pie and gold rim, generated by `assets/make_icon.py`.
- Tray icon: left click shows/hides the overlay; right click for compact mode, Settings, Copy and Exit.
- Spell icons: Data Dragon art in `assets/spells/*.rgba`, fetched by `assets/fetch_spell_icons.py`, drawn with a cooldown pie.
- Compact mode: lane label + two spell icons per enemy, time on the icon (header button, tray, or the ToggleCompact hotkey).
- Chat reading: the chat area is cropped on the GPU (staging texture), and OCR only runs when the text-like
  pixels change, so camera movement behind the chat does not trigger it.
- `src/`: `data` (Data Dragon), `cooldown`, `tracker`, `message`, `live`, `chat` (OCR line parser),
  `settings`, `win/*` (Windows integration), `ui/*` (overlay, Setup, installer, theme).

```
cargo test
cargo build --release
Flashless.exe --ocr-test <screenshot.png> [left top width height] [champions...]   (diagnostic, prints to stdout)
```
